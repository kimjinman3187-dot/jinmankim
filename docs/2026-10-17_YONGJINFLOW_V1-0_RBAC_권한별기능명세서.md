# 용진FLOW v1.0 권한별 기능 명세서

- 기준일: 2026-10-17
- 권한 원본: `users/{uid}.role`, `users/{uid}.status`
- 적용 계층: 화면 메뉴·클라이언트 동작·Firestore Security Rules

## 1. 공통 접근 조건

- Google 로그인이 완료되어야 한다.
- `users/{uid}` 문서가 존재하고 `status`가 `active`여야 한다.
- 화면에서 버튼을 숨기는 것만으로 권한을 판단하지 않는다. 최종 쓰기 허용 여부는 Firestore Rules가 다시 검사한다.
- 모바일은 현장 확인 중심, 수량·상태를 바꾸는 핵심 업무는 PC 중심으로 구성한다.

## 3. 생산·재고 권한 원칙

### 생산 담당자

- 생산 주문과 재고 현황을 볼 수 있다.
- 주문별 생산수량과 생산 단계를 등록할 수 있다.
- 재고 생산계획, 재고 입고 확정, 주문 배정, 출고, 반품, 정정은 할 수 없다.

### 생산관리자

- 생산 담당자의 기능을 모두 수행할 수 있다.
- 재고용 생산계획을 생성하고 품질 확인 후 입고를 확정할 수 있다.
- 가용재고 범위 안에서 주문에 재고를 배정한다.
- 배정 해제, 출고 확정, 전량 반품 입고, 사유가 있는 재고 정정을 처리한다.

### 관리자

- 생산관리자와 같은 생산·재고 처리 권한을 갖는다.
- 사용자 승인과 전사 운영 상태를 관리한다.

재고 원장은 생성 후 수정·삭제하지 않는다. 정정이 필요하면 사유가 남는 새 원장 이벤트로 처리한다.

## 4. 문서·회계 권한 원칙

- 기안자는 자신의 문서를 임시저장하고 제출 전 수정할 수 있다.
- 결재 요청 이후에는 허용된 상태 전이와 결재 순서를 따라야 한다.
- 결재자는 자신에게 배정된 단계에서 승인·반려한다.
- 회계·관리자 전용 지급 및 ERP 이관 필드는 일반 기안자 화면에 표시하지 않는다.
- 승인 완료 문서의 ERP 내보내기는 서버시간과 처리자 정보를 기록하고 중복 처리를 제한한다.
- 인쇄본에는 문서번호, 작성자, 결재자 서명·상태, 처리 이력, 첨부 요약이 포함된다.

## 6. 운영 검증 상태

- 자동 테스트와 에뮬레이터 검증은 릴리스 전 수행한다.
- 실제 생산·생산관리자 계정 생성 및 역할별 1회 로그인은 후속 운영 검증으로 이관한다.
- 실제 계정 확인 전에도 권한 코드는 동결할 수 있으나, 현장 투입 전 각 계정에서 메뉴와 허용 작업을 한 번씩 확인해야 한다.
