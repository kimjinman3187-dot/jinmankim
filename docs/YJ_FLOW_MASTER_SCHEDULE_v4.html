운영 원칙 현재 일정은 기능 개발 일정이 아니라 운영 전환형 마스터 스케줄이다. 데이터 자산화 2단계와 Auth 운영체계가 병렬 진행된 실제 이력을 반영한다. 향후 Auth 작업은 Google Login 최소 운영 로그인 완료 기준에서 PIN/sessionStorage/Rules 전환 순서로 관리한다.
⚠ 운영 주의사항 Delete Branch — PR 병합 완료 후 자동 제안되는 Delete Branch는 클릭하지 않는다. 브랜치는 참조 보존을 위해 유지한다.
Reset Data — 관리자 패널의 초기화 버튼은 운영 데이터를 영구 삭제한다. 절대 사용하지 않는다.
Firestore Rules — 운영 규칙 변경은 이 일정표에서 즉시 착수하지 않는다.
Auth 구현 — Google Login 최소 운영 로그인은 WORK22-6N-K3에서 완료됨. 이후 PIN/sessionStorage/Rules 전환은 별도 승인 전 착수 금지.
