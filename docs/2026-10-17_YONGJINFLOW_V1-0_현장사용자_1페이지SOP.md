# 용진FLOW v1.0 현장 사용자 1페이지 SOP

운영 주소: [https://kimjinman3187-dot.github.io/jinmankim/](https://kimjinman3187-dot.github.io/jinmankim/)

## 시작하기

1. 회사에서 승인받은 Google 계정으로 로그인합니다.
2. 처음 보이는 메뉴가 본인의 업무와 다르면 임의로 작업하지 말고 관리자에게 계정 역할을 확인합니다.
3. 휴대폰은 현황 확인, PC는 입력·수량 변경·결재 처리에 사용하면 가장 안전합니다.

## 생산과 재고 처리

| 해야 할 일 | 화면 | 처리 순서 |
|---|---|---|
| 주문받은 제품 생산 | 생산 | 주문 선택 → 이번 생산수량 입력 → 품질 확인 → 포장 → 출고 |
| 미리 만들어 재고 확보 | 생산 | 재고 생산계획 → 생산수량 등록 → 품질 확인 → 재고 입고 확정 |
| 재고를 주문에 사용 | 재고 | 품목·주문 선택 → 수량 확인 → 주문에 재고 배정 → 출고 확정 |
| 출고품 전량 반품 | 재고 | 출고 기록 선택 → 전량 반품 입고 |
| 수량 오류 바로잡기 | 재고 | 품목 선택 → 증감 수량과 사유 입력 → 재고 정정 |

- **현재 재고**: 창고에 실제로 있는 전체 수량
- **주문 예약**: 주문에 배정되어 다른 주문에 쓸 수 없는 수량
- **출고 가능**: 지금 새 주문에 배정할 수 있는 수량

모바일 재고 화면에서는 현재 재고·주문 예약·출고 가능 수량과 최근 원장만 확인합니다. 배정·출고·반품·정정은 오조작 방지를 위해 PC에서 처리합니다.

## 결재문서 처리

1. `내 결재문서`에서 문서 종류를 고르고 필수 항목을 입력합니다.
2. 작성 중에는 `임시저장`, 내용 확인 후에는 `결재 요청`을 누릅니다.
3. 첨부가 필요한 업무만 파일을 넣고, 표시된 파일명과 업로드 완료 상태를 확인합니다.
4. 반려되면 반려 사유를 확인해 수정한 뒤 재상신합니다.
5. 승인 문서는 `A4 요약본 인쇄 / PDF`를 사용합니다. 결재자·처리 이력까지 필요하면 `상세 이력본`을 사용합니다.

## 실수했을 때

- 재고 원장이나 운영 문서를 임의로 삭제하지 않습니다.
- 재고 수량 오류는 `재고 정정`에서 사유를 남겨 바로잡습니다.
- 로그인·저장·출력 오류가 나면 화면의 오류 문구와 발생 시각이 보이게 캡처해 관리자에게 전달합니다.
- `RESET DATA`는 운영 중 사용하지 않습니다.
- 같은 버튼을 여러 번 누르지 말고 처리 완료 안내가 나올 때까지 기다립니다.

## 운영 시작 전 한 번만 확인할 것

- 생산·생산관리자 등 실제 계정으로 각각 1회 로그인해 메뉴와 권한 확인
- 회사 더존 ERP가 요구하는 CSV 열 순서와 UTF-8 BOM/EUC-KR 인코딩 확인
- 휴대폰과 PC에서 글자 크기, 버튼 위치, 업무 용어가 이해되는지 실제 사용자 확인

위 점검에서 기능 장애가 없으면 그대로 운영을 시작합니다. 새 기능 제안은 현재 업무를 멈추지 말고 별도 개선 요청으로 기록합니다.
