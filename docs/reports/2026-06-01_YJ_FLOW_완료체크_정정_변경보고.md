## 8. STATIC-ASSET-404-1 결과 반영

작업명:

```text
STATIC-ASSET-404-1 — 이미지 정적 파일 404 원인 진단 및 최소 복구
```

원인:

```text
WOODS_DATA가 image_*.png 파일명을 참조하지만, 해당 이미지 원본이 repository/GitHub Pages 정적 파일 배포 경로에 존재하지 않는다.
그 결과 Sales 목재 카탈로그 썸네일 영역에서 image_*.png 404가 반복 발생했다.
```

영향:

```text
22-3E PC Finance 신규 승인 대기 리스트 기능 차단 없음.
PC Finance / PC Production / 모바일 공장 탭 / 입금처리 로직과 직접 관계 없음.
영향 범위는 Sales 목재 카탈로그 및 목재 선택 썸네일 표시 영역이다.
```

조치:

```text
B안 — 이미지 요청 차단 + 색상 fallback 사용

이미지 원본이 repository에 없으므로 누락 이미지 파일을 임의 추가하지 않았다.
이미지 파일 존재가 확실할 때만 img src 또는 background-image를 할당하도록 하고,
현재 미배포 image_*.png는 브라우저가 요청하지 않게 했다.
목재 선택 UI는 WOODS_DATA의 색상값과 목재명으로 유지한다.
```

검증:

```text
1. WOODS_DATA 고유 image_*.png 참조 17개 확인
2. repository 내 실제 image_*.png 파일 0개 확인
3. 목재 카탈로그 렌더링에서 미배포 image_*.png src 요청 차단
4. 선택 썸네일 및 woodPlate background-image도 색상 fallback 처리
5. GitHub Pages에서 Console image_*.png 404 해소 확인
```

보호:

confirmPayment 수정 없음
