## 5. Code Freeze 원칙

1. `v1.0.0-release`는 1차 개발 기준점으로 보존한다.
2. 운영 장애·보안 문제 외에는 v1.0에 신규 기능 또는 UI 변경을 넣지 않는다.
3. 사용법 문의는 SOP 보완, 기초정보 오류는 승인된 데이터 보정으로 처리한다.
4. 신규 기능과 구조 변경은 Phase 2 백로그로 등록한다.
5. 긴급 수정은 별도 브랜치·PR·회귀 테스트·운영 확인을 거친다.

아래 항목은 1차 개발 미완료가 아니라 실제 운영 환경에서만 확정할 수 있는 후속 점검이다.
