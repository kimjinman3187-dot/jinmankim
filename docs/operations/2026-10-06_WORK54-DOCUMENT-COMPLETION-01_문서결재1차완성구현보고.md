## 목적

WORK53에서 복구한 Spark 무료 요금제용 문서 기능을 실제 업무 흐름에 맞게 보완한다. 이번 단계는 승인 취소·처리 완료 기록의 화면/클라이언트/Rules 불일치를 해소하고, 정상적인 임시저장·수정 및 반복 가능한 자동 테스트 환경을 마련하는 데 한정한다.

## 구현 범위

- 문서 스키마를 `schemaVersion: 7`로 올리고, 처리 결과와 승인 취소 사유를 각각 `completionNote`, `cancellationReason`에 보존한다.
- 승인 완료 후 지급·정산·처리·배부가 시작되지 않은 문서는 작성자가 아닌 관리자가 사유와 함께 승인을 취소할 수 있다.
- 승인된 비지출 문서는 관리자 또는 허용된 작성자가 처리 결과를 기록할 수 있다. 지출결의서는 지급·정산 단계에서만 완료 처리하도록 계속 분리한다.
- 문서 5종을 필수값이 덜 입력된 상태로 임시저장하고, 작성자가 다시 불러와 수정한 뒤 결재 요청할 수 있다.
- 임시저장 시 결재선은 비어 있을 수 있으나 결재 요청 시에는 유효한 결재선과 모든 필수값을 다시 검사한다.
- 지출결의서 증빙은 임시저장에는 없어도 되지만 결재 요청 시 반드시 필요하다.
- 작성 중 문서의 첨부는 유지·전체 교체·전체 제거를 선택할 수 있다. 기존 첨부 삭제, 부모 문서 수정, 수정 이력 기록은 하나의 Firestore 트랜잭션으로 처리한다.
- 기존 `A4 인쇄 / PDF` 기능을 유지하며 문서 상세, 처리 결과, 승인 취소 사유가 출력 대상에 포함된다.

## Rules 및 보안

- 신규 문서와 수정된 임시문서는 스키마 7을 사용하며, 기존 스키마 6 문서의 상태 전이 호환성은 유지한다.
- 임시저장 수정은 본인 소유의 `draft` 문서에만 허용한다.
- 문서 종류, 작성자, 문서번호 등 불변 필드는 임시저장 수정으로 바꿀 수 없다.
- 임시저장 수정, 승인 취소, 처리 완료는 부모 문서와 불변 이력을 같은 원자 작업으로 기록해야 한다.
- 첨부 청크와 매니페스트 삭제는 본인 소유의 작성 중 문서에서만 허용한다.
- 승인 취소는 관리자·비작성자·미지급·미정산·미완료·미배부 조건을 모두 만족해야 한다.
- 처리 완료는 승인된 비지출 문서에만 허용하며 중복 완료를 차단한다.
- 지급 하위 컬렉션 쓰기와 화면의 지급 기능은 계속 비활성화한다.

## 사용자 경험 검토

- 작성 화면에서 `임시저장`과 `저장하고 결재 요청`을 명확히 분리했다.
- 임시저장 문서의 종류는 수정 중 변경할 수 없도록 잠그고, 입력값과 결재선을 다시 채운다.
- 첨부가 있는 문서를 수정할 때 새 파일을 선택하면 기존 첨부 전체가 교체됨을 안내한다. 파일을 선택하지 않으면 유지되며 별도 체크로 전체 제거할 수 있다.
- 제목이 없는 임시문서는 목록·상세에서 `제목 없는 작성 중 문서`로 표시한다.
- 결재 요청 실패 후에도 작성 중 문서와 입력 화면을 유지해 증빙 또는 필수값을 보완할 수 있다.
- 승인 취소와 처리 완료는 사유·결과 입력란을 해당 권한과 상태에서만 노출한다.
