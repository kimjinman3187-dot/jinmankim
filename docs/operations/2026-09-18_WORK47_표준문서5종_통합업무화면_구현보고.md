# WORK47 표준문서 5종 통합 업무화면 구현보고

- 기준일: 2026-09-18
- 기준 브랜치: `codex/work47-unified-document-workspace`
- 목적: WORK46 표준 문서 기능을 기존 화면 위에 추가된 별도 도구가 아니라 용진FLOW의 기본 문서 업무 흐름으로 통합한다.

## 변경 결과

### 내 결재문서

- 표준 문서 5종을 기본 작성 수단으로 표시한다.
- `새 문서 작성`, `내 문서`, `결재함`, `지급관리`, `전체 문서` 탭으로 업무 목적을 분리한다.
- 내 문서, 결재 대기, 반려, 지급 대기 지표를 같은 화면에서 확인한다.
- 선택한 탭에 따라 작성 폼과 문서 목록을 재구성한다.

### 결재 처리

- 현재 사용자가 처리할 표준 문서를 통합 결재함에 표시한다.
- 문서를 선택하면 내 결재문서의 동일 상세 화면으로 이동하므로 승인·반려·첨부·이력을 중복 구현하지 않는다.
- 기존 `document_approval_requests`와 지출결의 v3는 `이전 결재 기록`으로 접어 보존한다.

### 업무 홈

- 기존 일반결재 요약 대신 표준 문서 기준의 결재 대기, 반려, 지급 대기 건수를 표시한다.
- 기존 문서 수치가 신규 표준 문서 지표를 덮어쓰지 않도록 분리한다.

### 이전 문서 보존

- 기존 문서는 삭제하거나 변환하지 않는다.
- 신규 작성 기능과 기존 승인·반려 동작은 화면에서 제거한다.
- 목록, 상세, 첨부와 처리 이력은 접힌 읽기 전용 보관함에서 조회한다.

## 검증

- 기존 UI·첨부·결재 회귀 테스트: 65/65 통과

## 변경하지 않은 범위

- Firestore Rules 및 Storage Rules
- Firebase 설정 및 Functions
- `users`, `orders` 데이터
- Reset Data
- 기존 문서 데이터 삭제·마이그레이션

## 운영 확인 항목

1. 역할별로 내 문서·결재함·지급관리 탭이 올바른 자료만 표시하는지 확인
2. 업무 홈 지표와 표준 문서 목록 건수가 일치하는지 확인
3. 이전 문서 보관함에서 기존 기록이 읽기 전용으로 열리는지 확인
4. 모바일과 PC에서 작성 폼, 목록, 상세 화면의 배치 확인
